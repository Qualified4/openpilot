# CCNC 저속 인식 보류와 표시 기억 분리

2026-10-25. 오늘 주행 `0000041e--a4118e6770`의 “차선 꺼짐” 북마크 6개에서 저속 감속 시 C2의 `displayResetNs`가 계기판의 확정 색상 기억을 지웠다. 깜빡이 중 저속 추론은 `lane_change`로 중단된 상태라 다시 색상을 확정할 수 없었고, 계기판은 미확정인 것으로 처리해 양쪽 14를 유지했다. 주차장 숨김이 원인은 아니었다. 22/55.973초와 23/0.230초는 같은 연속 사건이며, 총 5개 초기화 사건이다.

사용자 요청에 따라 인식 증거와 표시 기억을 분리했다. 24km/h 미만의 인식 보류와 필터·추적 증거 초기화는 유지한다. 차선을 넘는 상황의 기존 `trackingReset`도 유지한다. 저속 감속을 이유로 계기판에 `displayResetNs`를 발행하던 경로와 그 용도의 상태만 제거했다. 새로 확정한 타입·색상은 기존 정책대로 표시를 교체한다. 모델·확률·확정 횟수·만료 시간을 바꾸거나, 보류 중인 결과를 새 인식으로 만들지 않는다.

계기판은 깜빡이·차선 변경 중과 저속 정차에서 마지막 확정 표시를 유지한다. 정상 주행에서 인식이 돌아오지 않는 경우의 기존 5초 유지 후 흐린 0, 차선 확률 저하의 0, 최초 색상 확정 전 14와 주차장 판정의 양쪽 14는 그대로다. 기존 수신기의 선택적 초기화 토큰 파싱은 호환을 위해 남겨 두었다. 주차장 진입 10m와 24km/h 이상 1초 해제도 유지한다.
