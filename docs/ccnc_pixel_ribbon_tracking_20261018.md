# Pixel Ribbon v2 — 실제 도색 선택과 공간 추적 검증

2026-10-18. 실제 목표 도색을 선택하고 추적하는 오프라인 구조를 구현했다. **도색 선택은 개선됐지만 실사 시간 정렬의 검증은 미완료다. GPU 학습과 모델 승격은 계속 보류한다.** 픽셀 보존/보간 문제를 반복 조사하지 않았으며 기존 모델·로그·검수 결과는 보존했다.

## 구현

`pixel_tracker.PaintTracker`가 기존 `pixel_ribbon.collect_pixels` 위에서 동작한다. modelV2 주변 ±0.9m는 탐색 범위이며, 실제 위치는 원본 RGB의 색상·도색 폭·도로 좌표에서의 방향·여러 미터의 지지 구간으로 보정한다. 기존 수집기의 기본 ±0.45m는 유지했다. 선택 결과는 원본 픽셀 좌표의 부분집합이며 리사이즈한 strip을 만들지 않는다.

색상별 후보를 분리해 경로를 맞춘다. 저채도 노란색이 흰색 후보에도 중복 포함되던 문제를 수정했다. 폭 4~30cm의 도색을 탐색하고, model 곡선에 대한 완만한 offset/slope를 거리별로 균등하게 평가한다. 행마다 밝은 점을 따라 중심을 바꾸지 않는다. 이전 경로는 ego motion으로 옮겨 현재 도색과 대응시킨다.

횡단보도·유도 표시에는 색상별 폭뿐 아니라 합친 도색 폭, 분기 부근의 폭 증가, 국소적인 연속성을 검사한다. 흐릿한 횡단 도색의 작은 밝은 조각을 목표 차선으로 선택하지 않도록 했다. morphology는 폭/연결성에 대한 **제외 판단**에만 사용하며 채워진 픽셀을 도색이나 공백으로 추가하지 않는다.

이중선은 두 도색을 별도 경로로 보존하며 종류는 ego에 가까운 member를 기준으로 한다. 바깥 실선이 안쪽 점선의 공백을 메우지 않는다. 경쟁하는 경계, 방향/폭/지지가 불충분한 도색, 가림은 UNKNOWN이다. 임계값은 제한된 실험의 휴리스틱이며 보정된 정답 확률이 아니다.

기존 daemon·ONNX·Xiaoge·CAN·CCNC 디버그·조향·가감속·차선 변경 코드는 수정하지 않았다. 신규 추적기를 실시간 프로세스에 연결하거나 의존성을 추가하지 않았다.

## 공간·시간 누적

4.5~20m의 관측을 최근 3초 동안 저장한다. 단순 전방거리 합산 대신 SE(2) 회전/이동으로 고정된 world 경계 polyline에 대응시키고 호장 0.25m bin에 기록한다. 같은 물리 bin을 여러 프레임에서 보더라도 길이가 늘어나지 않는다.

실사 ego motion은 카메라 EOF 이전에 도착한 carState와 livePose를 사용한다. wheel speed와 보정 좌표로 회전한 angular velocity를 카메라 시각 사이에서 적분한다. livePose 측정/수신 시각을 구분하며 age 150ms 이내만 허용한다. per-step 불확실성 proxy가 크면 누적하지 않는다. **이 proxy는 실제 누적 위치 오차의 검증된 상한이 아니다.** road z도 model의 지역 도로면 근사다.

미검출을 공백으로 바꾸지 않는다. 공백 후보에는 노출 도로의 밝기/질감, 정적 도로 optical flow와 ego 예측의 일치, 0.5m 이상 이동한 관측이 필요하다. UNKNOWN은 gap 길이에 포함하지 않으며 이전 증거의 timestamp를 갱신하지 않는다. 모순은 UNKNOWN으로 처리한다.

점선은 서로 다른 도색 그룹3개와 실제 검증된 내부 도로 공백2개 및 충분한 고유 관측 거리를 요구한다. 프레임 다수결을 쓰지 않는다. 실선은 22m 이상의 고유 관측과 거의 연속된 도색을 요구한다. 색상은 12m 이내 실제 도색을 별도 누적하고 두 번째 대응 관측 전에는 확정하지 않는다. 마지막 근거가0.5초를 넘으면 UNKNOWN이다. 차선 변경·추적 상실·시간 단절·큰 대응 오차는 상태를 초기화한다.

새 로그를 요구하거나 무작위 수집하지 않았다. 기존 검수 지점 주변을 각각 5Hz/3초/16프레임씩 정확 동기화해 사용했다.

합계3route/4세그먼트/5clip/80프레임이다. 기존 route 분할을 유지했고 test route로 규칙을 조정하지 않았다. 별도 합성 대조군은13종×16프레임이다.

이전 보고서에서 수동 trace의 정확도를 과대평가한 부분을 정정한다. `7039`의 근거리 trace 일부는 실제 도색에서 약10~20px 벗어나 있었고, `8355`도 흐릿하거나 횡단 도색으로 가려진 부분을 포함했다. 기존 보고서/라벨은 보존하고, 원본에서 식별 가능한 부분만 `annotation/paint-revised.json`으로 다시 추적했다. 앞선 픽셀 값 보존 결과와 실제 paint 정답의 정확성은 별개다. 이전 trace의 포함률을 실물 도색 정답 검증 수치로 재사용하지 않는다.

새 trace도 단일 assistant 검수이며 독립 사람 검수는 아니다. nominal polygon과 경계 오차만큼 깎은 내부 core를 함께 평가한다. core가 없어지는 불확실한 trace는 측정 불가다. 미표기 영역을 배경 정답으로 간주하지 않으며 새 라벨을 학습에 입학시키지 않았다.

## 실제 고화질 결과

포함률은 **분류 정확도나 노란색 Recall이 아니라 같은 가용 원본 행에서 부분 trace 픽셀을 선택한 비율**이다. 다른 trace를 사용한 이전 보고서와 개선율을 계산하지 않는다.

| 표본 | 좁은 ribbon 포함률 | 선택 도색 nominal 포함률 | 내부 core 포함률 | 확인된 도색 행의 가짜 공백 |
|---|---:|---:|---:|---:|
| 18379 흰 점선 | 100.00% | 59.75% | 측정 불가 | 측정 불가 |
| 38875 흰 점선 | 100.00% | 83.32% | 95.14% | 0/74행 |
| 8355 노란 이중선 | 88.49% | 89.73% | 98.95% | 0/61행 |
| 7039 노란 실선 | 100.00% | 99.26% | 100.00% | 0/133행 |
| 8042 횡단 도색 혼재 | 목표 trace 없음 | 측정 불가 | 측정 불가 | 측정 불가 |

좁은 ribbon은 탐색 영역 전체를 수집하므로 포함률이 높아도 주변 표시/배경을 함께 포함한다. 이중선/횡단 도색 장면의 명시된 주변 표지 포함은 각각1,702/19,362(8.79%),3,111/19,102(16.29%)에서 선택 후0픽셀로 줄었다. 이는 **라벨이 있는 주변 표시만의 혼입 결과**다. 모든 배경에 정답 mask가 없어 전체 혼입률·segmentation Precision/F1을 인증하는 수치가 아니다.

흰 점선의 누락은 해결되지 않았다. 첫 표본은 충분한 내부 core도 없어59.75%를 정확한 실물 Recall로 단정할 수 없다. 그림자·낮은 대비·마모와 trace 오차를 분리해야 한다. 확인 가능한 내부 도색268행의 가짜 공백은0행이지만 모든 공백의 진위를 검증한 결과는 아니다.

## 합성 결과와 남은 시간 정렬 문제

model의18cm 위치 오차, 흰색/노란색, 점선/실선, 이중선, 횡단 도색, 그림자, 가림, 곡선, 정차를 포함했다. 합성 원본에는 도색/주변 표시의 완전한 mask가 있다. 수치는 아래 자동 생성 표에 제공한다.

노란 점선5m/s에서는2.8초부터 점선을 확정했다. 느린 점선·흰 점선·실선+점선 혼합 이중선 일부는 UNKNOWN을 유지했다. 혼합 이중선의 포함률 약70.8%와 가림 장면 약18.3%도 낮은 결과 그대로 보고한다. UNKNOWN을 실선으로 강제하지 않았다. 이 결과는 실차 정확도나 실제 도색 전환 지연이 아니다.

실사에서는 원본 도색 위의 특징점을 별도의 forward/backward optical flow로 추적했다. 현재 선택 도색3px 주변에 남는 비율은 clip별84.0~100.0%였다. 그러나 같은 선 위에 있다는 사실만으로 같은 물리적 도색 조각을 증명할 수 없다. ego 예측과 image flow의 차이는 median7.55~121.74px, p95 37.81~203.33px로 컸다. 균일한 선을 따라 미끄러지는 aperture 문제/반복 질감 대응이 가능한 원인이지만 ego 적분·도로면 근사 오차도 배제하지 못했다. 큰 잔차를 제외해 좋은 수치만 제시하지 않았다. **실사의 정확한 공간 중복 제거와 판정 지연은 검증 완료가 아니다.**

80프레임의 종류 후보는 실선12/점선0/UNKNOWN68, 색상 후보는 흰색24/노란색30/UNKNOWN26이었다. 종류 확정률15.0%, 미확정률85.0%다. 실선 확정은 노란 실선 clip에만 있었다. 점선 출력0으로 실사 False Dashed 비율은 분모0, 측정 불가다. 3개 clip은 경로 상실/재연결로4~6회 초기화됐다. 이 단절을 이전 결과로 덮지 않았다. 실제 전환 시작 시각이 라벨링되지 않아 실사 판정 지연은 측정하지 않았다. 보고되는 상태 전환은 UNKNOWN을 포함한 분석 상태이며 실제 CCNC 표시 전환이 아니다.

## 적용 판단·재현

**실차 적용·GPU 학습 재개 검증은 미통과**다. 남은 검증은 같은 기존 clip의 흰색/그림자 source trace, 고유 질감·도색 끝점의 world 대응, 혼합 이중선 member 유지, 누적 위치 불확실성이다. 무작위 추가 로그를 전제로 하지 않는다.

기존/신규 HOLD를 유지했다. 체크포인트·ONNX·기본 OFF·CAN·디버그를 보존했다. comma가 연결되지 않아 Snapdragon CPU/RSS·modeld/controlsd·프레임 누락은 측정 불가다. full RGB와 검수 mask를 쓰는 오프라인 구현의 실시간 NV12 비용도 미검증이다.

산출물은 `.analysis/pixel-ribbon-tracking-20261018/`에 있다.

- `PREVIEW.html`: 80프레임 원본/선택 결과 slider·5Hz 재생·원본 크기 보기.
- `anchor-review/8355.png`, `7039.png`, `8042.png`: 원본과 선택 도색, 별도 mask.
- `real/*.npz`, `real-results.json`: source x/y·RGB, 프레임별 경로·UNKNOWN 사유·공간 누적.
- `annotation/paint.json`, `paint-revised.json`: 이전/수정 trace, 검수 범위와 한계.
- `quality.json`, `synthetic.json`, `validation-plan.json`: 분모·조건·코드 hash.
- `REPRODUCE.ps1`, `tests.txt`, `ruff.txt`, `preservation.json`: 재현/검사/보존 증거. 학습 명령 없음.
