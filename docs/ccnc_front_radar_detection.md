# CCNC 계기판 표시 기술 안내

현재 CCNC 표시 구조와 테스트 실행 방법을 정리합니다. 사용자용 기능 설명은 [한국어 설정 안내](user/ko/settings.md#ccnc-display)와 [영어 설정 안내](user/en/settings.md#ccnc-display)에 있습니다. 개발 과정의 수치·중간 구현·로그 재생 기록은 [검증 이력](ccnc_validation_history.md)에 보존합니다.

## 적용 범위

네 가지 표시 설정의 기본값은 모두 꺼짐입니다. `CcncModelLanes`는 끄기(0)·기본(1)·정밀(2) 선택기이며, 나머지는 ON/OFF입니다. 차선 색상과 차선 애니메이션은 CCNC 표시 경로에서 적용되고, 전방 레이더 차량 표시는 HDA1에만 적용됩니다. 위치 보정은 HDA1 레이더 차량 표시가 켜진 경우에 적용됩니다. HDA2에서는 레이더 차량 표시 옵션을 켜도 해당 경로를 실행하지 않습니다.

| 설정 | 표시 범위 | 상태 갱신 |
|---|---|---|
| `CcncLaneColor` | 주행 기어에서 가감속·주행 모드에 따른 강조 색상, 속도에 따른 강조 길이 | 색상 상태와 주행 모드 캐시 |
| `CcncModelLanes` | 기본: 원본 곡률 계산, 정밀: 개선 곡률 계산. 두 모드 공통으로 차선 위치·변경 강조·아이콘·전환, 속도 안내 적용 | 곡률 모드 전환 시 차선 필터·전환 상태·속도 안내 타이머 초기화 |
| `CcncRadarVehicles` | HDA1 전방·측면 차량 표시와 정차 시 표시 유지 | 차량 선택·유지·위치 필터 |
| `CcncVehiclePositionCorrection` | 차선 유지 차량 중앙 고정, 지속 횡이동 추종, 안정 후 복귀 | 전용 표시 중심·트랙별 횡이동·출력 상태 |

설정은 약 1초 주기로 갱신합니다. 색상 또는 차선 옵션의 전환은 레이더 차량 유지 상태를 초기화하지 않습니다. 차량 옵션 전환 시에는 차량 상태를 초기화합니다. 위치 보정 옵션 전환은 전용 보정 상태만 초기화하며 기존 차량 선택·필터·정차 기억은 유지합니다. 트레일러 관련 차선 변경 제한은 표시 효과보다 우선합니다.

## 코드와 입력

- [hyundaicanfd.py](../opendbc_repo/opendbc/car/hyundai/hyundaicanfd.py): 기본 CAN 메시지 생성, 설정 읽기, 선택한 표시 효과 호출, 최종 차량 아이콘 값 변환.
- [hyundaicanfd_ccnc_extension.py](../opendbc_repo/opendbc/car/hyundai/hyundaicanfd_ccnc_extension.py): 선택적 차선·색상 처리, `_CcncRadarLaneSelector`, `_CcncRadarDisplayTracker`, 차량 위치 필터.
- [card.py](../openpilot/selfdrive/car/card.py): `modelV2`, `radarState`, `liveTracks` 수신 상태 확인 및 전달.
- [interfaces.py](../opendbc_repo/opendbc/car/interfaces.py): 전달받은 입력을 CarState에 연결.
- [carstate.py](../opendbc_repo/opendbc/car/hyundai/carstate.py): 표시용 입력 초기화.

`card`는 다른 프로세스가 발행한 `liveTracks`를 구독합니다. 메시지가 valid/alive이고 수신 시각 기준 나이가 0 이상 150ms 미만일 때만 전달합니다. 유효하고 살아 있는 `radarState`도 함께 전달하며, 기본 차량 표시는 이를 사용할 수 있습니다. HDA1 레이더 차량 표시를 켜면 해당 표시 결과를 기본 선행차 표시로 덮어쓰지 않습니다.

## 확장 코드 정리

확장 모듈은 `hyundaicanfd_ccnc_extension.py`, 호출명은 `ccnc_extension`입니다. 테스트에서 확장 표시를 일괄 지정하는 인자는 `extended_ccnc`로 통일했습니다. 전방 레이더 차량 표시는 HDA1 전용이며, 기존 HDA2 차선·색상 효과는 계속 사용합니다.

호출되지 않는 필터의 `fill()` 함수, 전용 위치 필터의 미사용 필드, 차선 함수의 미사용 인자, 중복 초기화와 조건 검사를 제거했습니다. 차선 옵션이 꺼진 경우 먼저 반환하도록 흐름을 단순화했습니다. 차량 선택·추적 클래스는 구문 트리 비교로 변경이 없음을 확인했습니다. 일반 필터의 가변 계수 경로는 전용 필터의 동등성 시험에 사용하므로 유지합니다.

정리 후 전용 테스트 419개가 통과했습니다. Windows에서는 전체 저장소 스키마를 임시 ASCII 경로에서 읽고 실제 Params 접근을 차단한 시험 환경을 사용했습니다. 변경 전후에 세 설정의 모든 조합, HDA1/HDA2, 차선 소실·변경, 트레일러 제한을 포함한 640회의 연속 메시지 생성 결과가 일치했습니다. 합성 입력의 비교이며 실차 검증은 아닙니다.

## 전방 차량 표시 흐름

1. 전방 레이더 출처의 유한한 좌표·속도를 가진 후보를 확인합니다. 순정 SCC와 코너 레이더 점을 이 후보에 섞지 않습니다.
2. 새 레이더 관측의 연속성과 차선·경로 정보를 확인합니다. 같은 발행 데이터를 반복 처리한 횟수로 새 관측 수를 늘리지 않습니다.
3. 차선 기준으로 정면·좌측·우측 후보를 분류하고 곡률을 보정합니다. 측면 후보에는 거리·속도·차로폭·경계 조건을 적용합니다.
4. 차선 정보가 부족하면 영상 선행차와 모델 경로를 이용해 정면 후보를 보완합니다. 영상 정보만으로 레이더 차량을 새로 만들지는 않습니다.
5. 각 슬롯에 최대 한 대를 선택하고 트랙별 필터를 거쳐 계기판에 표시합니다. 차량 아이콘 변환은 기본·추가 표시 처리 이후에 적용합니다.

측면 후보의 원시 종거리 상한은 80m입니다. 연속 관측되는 기존 측면 차량은 차선이 잠시 사라졌을 때 마지막 유효 차선 정보를 최대 2초 또는 자차 이동 30m까지 사용할 수 있습니다. 관측이 끊기거나 대상이 바뀌면 이 연속 표시가 끝납니다. 정차 유지와 경계 근접 정지점 제외는 별도 조건이며, 모든 정지 반사점을 차량으로 유지하지 않습니다.

차량 선택·표시 필터는 CCNC 표시 전용입니다. 원본 레이더 점이나 주행 제어용 선행차를 이 경로에서 수정하지 않습니다. 후측방 아이콘은 사각지대 감지 상태를 나타내며, 개별 차량의 측정 거리·정확한 위치를 나타내지 않습니다.

정차·정차 접근 중 좌우 차량 기억의 저장·갱신은 원시 레이더 종거리 `dRel <= 15m`인 후보로 제한합니다. CAN 표시 거리의 0.8배 변환 전 기준입니다. 기존 연속 관측·정지·횡단 제외 조건은 유지하며, 적격 접근 기억은 정차 기억으로 이어집니다. 15m보다 먼 실시간 후보의 선택·표시는 기존 조건을 사용합니다. 이 임시 제한은 먼 실제 정차 차량의 미검출 기억도 줄이며, 구조물 판정의 수집 범위나 이동 예외는 변경하지 않습니다.

2026-10-06 검증: 표시 테스트 358개와 Wiki 테스트 27개가 통과했습니다. 새 거리 경계 회귀는 좌우·정차·접근과 14.99/15.00/15.01/27.25m를 확인하며, 이전 저장 로직에서는 원거리 8개 조합이 실패합니다. 비연속 구간 두 개의 총 2,400개 송신 시점 재생은 앞서 시험한 15m 제한과 동일하고 선택 대상·FF 출력은 유지됩니다. 한 정차 사례의 문제 시간대 RF 표시가 643개에서 24개 송신 시점으로 줄고 LF 검출은 유지됐습니다. 기록 입력 결과이며 실차 표시·실제 원거리 차량 누락은 검증하지 않았습니다. 로그·영상·상세 재생 결과는 로컬 분석 보관소에만 보존합니다.

### 구조물 판정 보완 롤백 (2026-10-07)

사용자 요청으로 2026-10-06의 구조물 수집 범위 확대와 최근 이동·영상 근거에 따른 예외 재검토를 되돌렸습니다. 구조물 판정은 이 보완 전 상태로 돌아가며, 별도로 적용한 정차·접근 기억의 15m 저장 제한은 유지합니다. 112구간 비교의 전체 좌우 표시 감소 수치는 정상 차량과 구조물 표시를 합산한 값으로, 정상 차량 누락이 확인됐다는 뜻은 아닙니다. 그 검증의 상세 결과와 기존 구현 설명은 로컬 분석 보관소에 보존합니다.

### 경계 부근 정지점의 대표점 선택 (2026-10-07)

정지점으로 허용된 후보도 새 관측에서 차선 경계 근접 여부를 계속 확인합니다. 기존 기준인 경계 거리 0.3m 이하·해당 경계 확률 0.1 초과가 연속 0.5초 이상, 서로 다른 관측 7회 이상 유지돼도 그 점을 차단하거나 차량 표시를 지우지는 않습니다. 실제 이동으로 허용된 차량은 기존대로 경계에 걸쳐 정차할 수 있습니다. 반복 발행·예측 관측은 이 확인 시간을 늘리지 않으며, 새 관측에서 경계 근접 근거를 잃으면 누적을 취소합니다.

가장 가까운 측면 후보가 위 조건과 현재 안쪽 차선 경계 거리 0.3m 이하를 만족하면, 같은 측면의 기존 적격 후보 중 더 내부에 있는 정지점을 대표점으로 선택할 수 있습니다. 대체점은 안쪽 경계에서 0.6m 이상 떨어져 있고, 원래 점과 종·횡거리 차이가 각각 1.5m 이하여야 합니다. 종·횡속도는 각각 절댓값 2km/h 이하이며 0.5초 이상 연속 관측된 현재 측정점이어야 합니다. 여러 대체점은 기존 제곱거리 순위로 비교합니다. 대체점이 없으면 원래 후보를 유지합니다. 두 점이 같은 차량이라는 확정이나 원본 ID 병합은 아닙니다.

이 처리는 위치 보정 옵션과 독립적인 CCNC 좌우 대표점 선택입니다. 기존 후보의 거리·속도·차로폭·도로 경계 조건, 정차 기억의 15m 제한, 전방 후보와 주행 제어 레이더는 유지합니다. 가까운 두 물체를 구분하는 정답 정보가 없으므로 같은 차량 여부와 실차 표시 품질은 별도 검증이 필요합니다.

표시 테스트 369개가 통과했습니다. 기록 설정과 같은 위치 보정 ON으로 79구간·91,510개 송신 시점을 비교했으며, 한 구간의 우측 대표점 1,128개 시점만 변경됐습니다. 나머지 구간의 모든 FF/LF/RF 표시 필드와 전체 비교의 표시 유무는 동일했습니다. 해당 구간의 정차 RF를 유지하며 경계 쪽 점 대신 내부 점을 선택합니다. 별도 교차로의 순간 RF 사례는 이 변경으로 해결되지 않습니다. 영상·로그·상세 결과는 로컬 분석 보관소에만 보존합니다.

같은 날 전체 로컬 로그를 재조사하니 기존 목록에 빠진 35구간이 있었습니다. rlog 123개에서 내용이 같은 중복 9개를 제외한 114구간을 위치 보정 ON/OFF 각각 133,504개 시점으로 비교했습니다. 입력이 아직 갖춰지지 않은 시작 부분의 송신 2,195개는 각 비교에서 제외했습니다. 두 설정 모두 같은 한 구간의 RF 대표점·출력 1,128개 시점과 이에 따른 정차 기억 1,120개 시점만 바뀌었습니다. 나머지 113구간의 모든 FF/LF/RF 표시 필드·선택 ID·정차/접근 기억은 동일하며, 전체의 표시 유무도 유지됐습니다. 변경 구간의 초반 짧은 대표점 왕복은 기존에도 있던 현상이고, 수정으로 생긴 차이는 약 3.72초부터 내부 점을 유지하는 부분입니다. 모든 로그를 계산 비교하고 변경 장면의 영상을 대조한 결과이며, 모든 영상의 모든 물체를 수동 판독하거나 실제 계기판을 검증한 결과는 아닙니다.

## 선택적 차량 위치 보정

`CcncVehiclePositionCorrection`은 HDA1 표시 입력의 시간 연속성 검증과 선택 유지, 선택 후 중앙 보정을 함께 적용합니다. 원본 레이더 메시지를 복사해 표시용 관측만 만들며 실제 레이더 처리·선행차 제어에는 연결하지 않습니다. FF 중심은 0m, LF/RF 중심은 기존 차선 geometry의 인접 차선 중심입니다. LF/RF 중심은 시간상수 1초의 지수 필터와 최대 0.3m/s 변화 제한으로 갱신합니다. 유효하지 않은 중심 입력은 필터에 넣지 않고, 신규 중앙 고정도 허용하지 않습니다. 연속된 기존 고정은 아래 유지 조건을 별도로 적용합니다.

- 중앙 유지 중에는 작은 흔들림과 한두 번의 큰 좌표 튐으로 고정을 풀지 않습니다. 새 표시나 옵션 ON 전환도 측정 위치에서 중앙으로 최대 0.3m/s로 이동합니다.
- 최근 약 0.6~0.7초의 서로 다른 레이더 관측 5개 이상에서 원시 및 곡률 보정 횡좌표가 같은 방향으로 각각 0.2m 이상, 평균 0.3m/s 이상 이동해야 지속 횡이동으로 판단합니다. 순이동량은 총 이동량의 80% 이상이어야 하며 한 관측의 변화가 순이동량 절반을 넘을 수 없습니다.
- 관측 간 원시 횡좌표 변화가 `0.04m + 2m/s × dt`, geometry 보정 변화가 `0.04m + 3m/s × dt`를 넘으면 **이동 판단 창만** 초기화합니다. 별도의 안정 복귀 창은 유지합니다. 기존 필터의 지연이나 단발 계단 변화로 만들어진 완만한 출력 이동을 횡이동 증거로 사용하지 않습니다.
- 추종 상태에서는 기존 필터를 거친 실제 곡률 보정 횡위치를 사용하고 데드밴드를 우회합니다. 일반 추종 출력의 최대 이동 속도는 1.5m/s이며, 아래의 빠른 이동 확인 시 적응형 속도를 사용합니다. LF/FF/RF 슬롯 변경 시에도 같은 물리 좌표의 출력 상태를 이어갑니다. 슬롯 변경은 중앙 고정 이력도 해제하고 일반 이동·안정 창을 다시 시작합니다. 빠른 이동 창은 같은 좌표 기준이면 슬롯을 넘어 유지합니다. 같은 슬롯의 좌표 기준 변경은 판단 창만 지우며, 차선 기준이 유효해지면 기존 중앙 고정 이력으로 복귀할 수 있습니다.
- 안정 복귀 창은 서로 다른 관측 5개 이상으로 최소 1초를 실제로 덮습니다. 기존 필터를 거친 횡좌표의 양 끝 약 10%(각 최소 1개)를 제외한 폭이 0.2m 이하이고, 창의 처음·끝 각 1/3 중앙값의 차이가 0.1m/s 이하이면 복귀를 검토합니다. 원시·도로 기준 좌표의 중앙값 추세가 같은 방향으로 모두 0.1m/s를 넘으면 계속 이동 중으로 보아 복귀하지 않습니다.
- 원시·도로 기준 좌표의 중앙값 추세가 반대 방향으로 각각 0.1m/s를 넘으면 곡률 보정의 영향이 큰 경우로 보고, 엄격한 폭 조건 대신 중앙 복귀를 검토할 수 있습니다. 두 복귀 경로 모두 현재 신뢰 가능한 차선 내부여야 하고 창의 80% 이상에서 경계 안쪽 0.35m 여유를 만족해야 합니다. 이 규칙은 실제 커브나 차선 유지의 증명이 아니며 커브 중 실제 차선 변경을 잘못 해석할 가능성은 남습니다.
- 신규 중앙 고정과 지속 이동 후 안정 복귀에는 관련 양쪽 차선 확률 0.6 이상의 기존 신뢰 조건이 필요합니다. 차량 위치와 표시 중심이 해당 차선 양쪽 경계에서 0.35m 이상 떨어져 있어야 합니다. 같은 ID·관측 세대·슬롯의 연속된 기존 중앙 고정은 양쪽 확률 0.3 이상에서 유지할 수 있습니다. 인접 중심 갱신은 계속 0.6 이상에서만 허용하며 낮은 확률에서 마지막 중심을 사용합니다. 0.3 미만의 추가 신뢰 저하는 유효한 현재 경계와 내부 여유가 있을 때 최대 0.5초까지만 견딥니다. 이 시간은 제어 프레임으로 계산해 같은 레이더 관측의 재처리로 연장되지 않습니다.
- 실제 지속 이동으로 중앙 고정을 해제한 상태와, 경계·신뢰 불확실성 때문에 측정 위치를 임시 출력한 상태를 구분합니다. 후자는 기존 고정 이력을 보존하며 현재 경계·확률 유지 조건이 다시 만족되면 중앙으로 부드럽게 복귀합니다. 지속 이동이 확인되면 이력을 해제하고 안정 창을 기다립니다. 경계에 걸치거나 배열/차선 기준이 없을 때는 이력과 관계없이 즉시 측정 추종 모드입니다.
- 일반 주행 중 같은 차량이 빈 표시 슬롯으로 넘어가면 0.2초 이상·서로 다른 레이더 관측 3회 이상 지속될 때 최종 CAN 슬롯을 전환합니다. 보류 중에도 현재 관측의 거리·검출 상태·물리 횡출력을 사용하고, 슬롯별 횡좌표 부호만 변환합니다. 원래 차량 선택·판정 이력은 변경하지 않습니다. 이전 슬롯에 다른 후보가 나타나거나 현재 측정/출력 부호를 그 슬롯에서 표현할 수 없으면 즉시 전환합니다. 선택에서 사라진 ID를 기억해 표시하지 않으며 관측 세대·연속성 상실 시 보류 이력을 버립니다. 정차·정차 접근·접근 기억 표시에서는 보류를 해제해 기존 처리를 유지합니다.
- 반복 처리한 같은 레이더 발행 데이터는 이동·복귀 시간을 쌓지 않습니다. 슬롯/좌표 기준 변경은 일반 이동·안정 창을 지우며, 150ms 초과 관측 간격도 안정 창을 다시 시작합니다. 제한 시간 안의 미검출과 유일한 ID 재연결은 아래 규칙으로 이력을 보존합니다. 큰 위치 재사용, 전체 입력 단절 또는 표시 처리 간격 150ms 초과는 이전 트랙 보정 상태를 이어받지 않습니다.

횡이동 판정은 표시용 휴리스틱이며 실제 차선 변경을 증명하지 않습니다. 자차 회전과 레이더 반사점 오차를 별도의 yaw 입력으로 보상하지 않으며, 빠른 이동이나 큰 잡음에서는 추종이 늦어질 수 있습니다. 실제 선행차 판단·제어·후측방 사각지대 아이콘과 원본 레이더 데이터는 변경하지 않습니다. 옵션 ON에서는 표시용 차량 선택·거리·검출 상태가 바뀔 수 있습니다.

## 표시용 시간 연속성 검증 (2026-10-02)

- 확인된 트랙은 이전 거리와 상대속도로 다음 거리를 예측합니다. 거리·횡위치·상대속도 잔차를 각각 검사하므로 속도 이상값 하나가 정상 위치와 차량 확인 이력을 지우지 않습니다. 단발 이상값은 해당 성분의 예측을 쓰며 여러 관측의 일관된 이동은 재검토합니다. 성분별 허용 잔차는 거리 `0.5 + 2dt` m, 횡위치 `0.35 + 2dt` m, 상대속도 `1 + 5dt` m/s입니다. 여기서 dt는 직전 표시 상태 이후의 초 단위 시간이며 고정 센서 오차 모델이나 물리 한계의 증명은 아닙니다. 게이트 밖에서도 최소 3관측·100ms의 일관성을 확인하며, 종방향 연속성에는 관측 상대속도를 함께 사용합니다.
- 새 차량은 서로 다른 관측 3회 이상과 150ms 이상의 관측 이력이 필요합니다. 한두 프레임짜리 후보에는 미검출 연장을 주지 않습니다. 큰 위치 재배치는 새 표시 ID로 다시 확인합니다.
- 이미 표시한 확인 차량의 미검출·위치 이상은 마지막 정상 위치 관측부터 최대 300ms만 예측합니다. 예측은 새 검출, 횡이동/안정 판정, 정차·접근 기억의 갱신 근거가 아닙니다. 전체 입력 중단·150ms 초과 입력 공백은 즉시 이력을 버립니다.
- ID 재연결은 이전 원시 ID가 현재 입력에 없고, 최근 표시한 확인 차량이며, 거리·횡위치·속도 조건을 만족하는 후보가 양방향으로 하나이고 서로 다른 두 관측에서 이어질 때만 허용합니다. 재연결 검토 범위는 마지막 정상 위치부터 350ms입니다. 후보 게이트는 예측 거리 오차 `1 + 2dt` m, 예측 횡위치 오차 `0.5 + 2dt` m, 상대속도 차이 2m/s입니다. 두 번 확인한 재연결 위치는 이 더 넓은 게이트를 사용하고 상대속도는 별도로 검증합니다. 모호한 경우 새 차량 확인을 기다립니다.
- 정상 선택 조건을 잠시 잃은 기존 차량은 마지막 정상 선택부터 최대 300ms 유지합니다. 다른 슬롯에 실제로 선택됐거나 경계 진입 거절 상태이면 유지하지 않습니다. 2m 이상 가까운 새 후보는 즉시 우선하며, 비슷하거나 먼 후보로의 교체에는 150ms와 관측 3회를 확인합니다. 정차·정차 접근의 선택 유지에는 기존 처리를 사용합니다.
- 빠른 횡이동은 최근 최대 6개의 새 관측에서 원시·도로 기준 좌표의 방향 일치, 순이동 0.4m 이상, 평균 0.8~15m/s, 순이동/총이동 80% 이상, 최대 단일 변화/순이동 70% 이하를 요구합니다. 최소 관측 3개·100ms 조건도 충족해야 합니다. 확인 시 중앙 고정을 해제하고 도로 기준 위치를 최대 `min(15, 1.4 × 확인 속도 + 1)` m/s로 추종합니다. 작은 진동과 한 번의 계단 변화는 이 빠른 경로의 근거가 아닙니다.
- FF에서 측면으로 이동할 때 보정된 물리 좌표의 부호를 측면의 unsigned CAN 필드로 표현할 수 없다면, 비어 있는 기존 FF에서 좌표를 이어갑니다. 다른 차량의 슬롯을 덮어쓰지는 않습니다. 정차·접근 중에는 일반 슬롯 지연을 적용하지 않되 이 부호 표현 처리만 허용합니다. 실제 차선 변경의 식별이나 차량별 센서 오류 제거를 보장하는 추적기는 아닙니다.
