## 배포 범위

`lane_strip_v4.onnx`와 메타데이터, 배포 파일 검사를 함께 갱신한다. graded latch,
색 완화, 지속 증거 누적, 반대 증거 전환 실험은 적용하지 않는다. 모델 구조·차량 제어·
설정 기본값 변경이나 새로운 기기 추론 시간 측정은 포함하지 않는다.
`deviceValidated=false`를 유지하며 실제 주행 수용 검증을 주장하지 않는다.

기기 적용은 오프로드 상태 확인 후 저장소 업데이트·일반 재시작을 거쳐, 기본 모델
로더와 Recogniser가 같은 UB 해시를 읽는지 확인한다. 설치·재시작·로딩 완료 여부는
배포 영수증으로 별도 기록한다.

비공개 분석 근거는 `.analysis/ccnc-field-412-20261022/claude/certlabel1026/`의
`round1108b`, `persistreview1108/card-human.json`, `deployUB1108`에 보존한다.
